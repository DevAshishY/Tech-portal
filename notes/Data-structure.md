## data structure 
A data structure is a way of organizing and storing data in a computer so it can be accessed and manipulated efficiently. It defines the layout and operations that can be performed on the data, helping to solve problems or perform tasks more effectively.

## Types of Data Structures

**1. Primitive Data Structures**
   
```
Integer (e.g., 42)
Float (e.g., 3.14)
Boolean (e.g., true, false)
Character (e.g., 'a')
String (e.g., "Hello")
```

**2. Non-Primitive Data Structures**

##### Linear Data Structures:

```
 Array: A collection of elements stored in contiguous memory locations.

    Example: [1, 2, 3, 4]

Linked List: A sequence of elements where each element points to the next.

    Example: 1 -> 2 -> 3 -> 4

Stack: A collection following LIFO (Last In, First Out).

    Example: Push 5, Pop 5.

Queue: A collection following FIFO (First In, First Out).

    Example: Enqueue 1, Dequeue 1.
```
##### Non-Linear Data Structures:
```
Tree: A hierarchical structure with a root node and child nodes.

    Example: Binary Tree.

Graph: A set of nodes (vertices) connected by edges.

    Example: Social Network.

Trie: A special tree used for searching strings efficiently.
```

## Property of Algo

an algorithm is a well-defined set of instructions or rules designed to perform a specific task or solve a problem. To be effective and reliable, an algorithm typically exhibits the following key properties:

**Finiteness**
The algorithm must have a finite number of steps. It should terminate after a limited number of operations.

**Definiteness**
Each step of the algorithm must be clear and unambiguous. Every instruction should have a precise meaning that can be executed without confusion.

**Input**
An algorithm should accept zero or more inputs. Inputs are the external data provided to the algorithm for processing.

**Output**
The algorithm must produce at least one output. Outputs are the results or the data derived from processing the inputs

**Effectiveness**
Every step of the algorithm should be simple enough to be performed in a finite amount of time and computationally feasible.

## Algorithm complexity 
refers to the efficiency of an algorithm in terms of the resources it consumes. The two most important types of complexities are:

**Time Complexity:**     Measures the time an algorithm takes to complete based on the size of the input (denoted as n).

**Space Complexity:**  Measures the memory an algorithm uses during execution.
